# Navigate Pavan Rao's website

Use this skill when a user asks about information published on
https://pavanpej.com. Fetch the relevant page before answering so that dates,
roles, and other details come from the current site.

## Find the right source

- [Homepage](https://pavanpej.com/): introduction, interests, and public profile links.
- [Career](https://pavanpej.com/career): professional experience, skills, education, and certifications.
- [Resume](https://pavanpej.com/resume): resume page, with a link to the downloadable PDF.
- [Experiences](https://pavanpej.com/experiences): travel pages and maps.
- [Road trips](https://pavanpej.com/experiences/road): road trip content.
- [USA footprint](https://pavanpej.com/experiences/usa): places visited in the United States.
- [Music](https://pavanpej.com/music): published playlist content and links.

For machine-readable navigation, fetch [site.json](https://pavanpej.com/site.json).
Use the [sitemap](https://pavanpej.com/sitemap-index.xml) to discover other pages.
The site serves public content without sign-in; it does not offer an MCP server
or an authenticated agent API.

## Use the information

Cite the source page for factual answers. If a requested detail is absent or a
map or embedded playlist cannot be read, state that limitation rather than
inferring unpublished information. Follow links to external profiles only when
the user's request needs them; this skill does not authorize contacting anyone
or modifying external services.

Content usage preferences are published in
[robots.txt](https://pavanpej.com/robots.txt): search and AI input are allowed;
AI training is disallowed.
